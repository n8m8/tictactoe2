# Sound Effects

This directory should contain MP3 sound files for the game.

## Required Sound Files

Add the following MP3 files to this directory:

- `move.mp3` - Played when a player makes a move
- `win-mini.mp3` - Played when a mini-game is won
- `win-game.mp3` - Played when the overall game is won
- `draw.mp3` - Played when a game ends in a draw
- `button-click.mp3` - Played when buttons are clicked
- `error.mp3` - Played when an invalid action is attempted

## Sound Sources

You can find free game sound effects from:

- [Freesound.org](https://freesound.org/)
- [Zapsplat.com](https://www.zapsplat.com/)
- [Mixkit.co](https://mixkit.co/free-sound-effects/)

## File Format

- Format: MP3
- Recommended sample rate: 44.1kHz
- Recommended bit rate: 128kbps or higher
- Keep file sizes small (< 100KB each) for fast loading

## Installation

Download sound effects and save them with the exact filenames listed above.
The game will automatically play them when the corresponding events occur.

Sounds can be muted/unmuted in the Options menu.
