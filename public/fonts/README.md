# Bunny Fonts

Download the following fonts from [Bunny Fonts](https://fonts.bunny.net/):

1. **Permanent Marker** - For game pieces (X/O)
   - Download: https://fonts.bunny.net/permanent-marker
   - File: `PermanentMarker-Regular.woff2` (~14KB)

2. **Caveat** - For UI text
   - Download: https://fonts.bunny.net/caveat
   - Files:
     - `Caveat-Regular.woff2`
     - `Caveat-Bold.woff2`

Place the downloaded .woff2 files in this directory.

## Installation

```bash
# Download fonts manually or use:
curl -o public/fonts/PermanentMarker-Regular.woff2 "https://fonts.bunny.net/permanent-marker/files/permanent-marker-latin-400-normal.woff2"
curl -o public/fonts/Caveat-Regular.woff2 "https://fonts.bunny.net/caveat/files/caveat-latin-400-normal.woff2"
curl -o public/fonts/Caveat-Bold.woff2 "https://fonts.bunny.net/caveat/files/caveat-latin-700-normal.woff2"
```
